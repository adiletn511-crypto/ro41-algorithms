## 1. Трассировка сортировки выбором (Selection Sort)

**Исходный массив:** `a = {5, 2, 9, 1, 7}` ($n = 5$)

| Проход `i` | Индекс минимума (`minIdx`) | Массив после обмена | Число сравнений |
| :--- | :--- | :--- | :--- |
| `0` | `3` (значение `1`) | `{1, 2, 9, 5, 7}` | 4 |
| `1` | `1` (значение `2`) | `{1, 2, 9, 5, 7}` | 3 |
| `2` | `3` (значение `5`) | `{1, 2, 5, 9, 7}` | 2 |
| `3` | `4` (значение `7`) | `{1, 2, 5, 7, 9}` | 1 |

* **Общее число сравнений:** $4 + 3 + 2 + 1 = 10$ (по формуле $\frac{n(n - 1)}{2} = \frac{5 \cdot 4}{2} = 10$).

## 2. Трассировка сортировки вставками (Insertion Sort)

**Исходный массив:** `a = {4, 3, 2, 1}` ($n = 4$)

| Проход `i` | `key` | Число сдвигов | Массив после вставки |
| :--- | :--- | :--- | :--- |
| `1` | `3` | 1 | `{3, 4, 2, 1}` |
| `2` | `2` | 2 | `{2, 3, 4, 1}` |
| `3` | `1` | 3 | `{1, 2, 3, 4}` |

* **Всего сдвигов:** $1 + 2 + 3 = 6$.
* **Сравнений на уже отсортированном массиве из 4 элементов:** **3 сравнения** (на каждом из 3 проходов `i = 1, 2, 3` выполняется ровно по 1 сравнению `a[j] > key`, условие сразу ложно, внутренний цикл `while` не делает сдвигов).

## 3. Трассировка бинарного поиска (Binary Search)

**Массив:** `a = {1, 3, 5, 7, 9, 11, 13}` (индексы `0..6`)

### Поиск `x = 7`

| Шаг | `lo` | `hi` | `mid` | `a[mid]` | Решение |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 0 | 6 | 3 | 7 | `a[3] == 7` — элемент найден, возврат индекса `3` |

### Поиск `x = 6`

| Шаг | `lo` | `hi` | `mid` | `a[mid]` | Решение |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 0 | 6 | 3 | 7 | `7 > 6` $\rightarrow$ ищем слева: `hi = mid - 1 = 2` |
| 2 | 0 | 2 | 1 | 3 | `3 < 6` $\rightarrow$ ищем справа: `lo = mid + 1 = 2` |
| 3 | 2 | 2 | 2 | 5 | `5 < 6` $\rightarrow$ ищем справа: `lo = mid + 1 = 3` |

* **Чем закончится поиск `x = 6`:** после 3-го шага `lo = 3`, `hi = 2`. Условие цикла `lo <= hi` (`3 <= 2`) становится ложным, цикл завершается. Обычный бинарный поиск вернёт `-1` (элемент не найден).
* **Что вернёт `LowerBound(6)`:** вернёт индекс **`3`** (значение `lo`, указывающее на первый элемент массива, который больше или равен `6`, то есть `a[3] = 7`).
