## Исходная функция
```csharp
static int F(int n) 
{ 
    if (n <= 1) return 1; 
    return n * F(n - 1); 
\`\`\`

## 1. Базовый случай и шаг рекурсии

* **Базовый случай (условие выхода):** `if (n <= 1) return 1;` — при достижении значения n <= 1 функция прекращает вызывать саму себя и возвращает 1.
* **Шаг рекурсии (рекурсивный переход):** `return n * F(n - 1);` — задача сводится к подзадаче меньшего размера путём вызова функции с аргументом n - 1 и умножения результата на текущее значение n.

## 2. Ручная трассировка вызова F(4)

| Вызов | Глубина | Действие (спуск вниз по стеку) | Возвращает (подъём вверх по стеку) |
| :--- | :---: | :--- | :--- |
| F(4) | 1 | 4 * F(3) | 4 * 6 = 24 |
| F(3) | 2 | 3 * F(2) | 3 * 2 = 6 |
| F(2) | 3 | 2 * F(1) | 2 * 1 = 2 |
| F(1) | 4 | Базовый случай (1 <= 1) | 1 |

### Ход выполнения
1. **Спуск по стеку (вызовы вниз):** F(4) (глубина 1) -> F(3) (глубина 2) -> F(2) (глубина 3) -> F(1) (глубина 4, базовый случай).
2. **Подъём по стеку (возвраты вверх):** F(1) возвращает 1 -> F(2) возвращает 2 * 1 = 2 -> F(3) возвращает 3 * 2 = 6 -> F(4) возвращает 4 * 6 = 24.

## 3. Что произойдёт при вызове F(-1), если условие заменить на n == 1?

При вызове `F(-1)` с условием `if (n == 1) return 1;` произойдёт **бесконечная рекурсия**, которая приведёт к ошибке **`StackOverflowException`** (переполнение стека вызовов).

**Причина:**
1. На первом шаге проверка `-1 == 1` ложна (`false`).
2. Функция вызывает `F(-2)`, затем `F(-3)`, `F(-4)` и так далее.
3. Поскольку значение `n` на каждом шаге уменьшается на 1, оно уходит в минус бесконечность и никогда не станет равно `1`. Базовый случай никогда не сработает.
4. Каждый вызов занимает память в стеке вызовов (Call Stack). Когда память стека закончится, программа аварийно завершится с ошибкой `StackOverflowException`.
