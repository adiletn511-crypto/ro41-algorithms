## 1. Ручная трассировка циклического сдвига влево на одну позицию

**Алгоритм:**
1. Сохраняем первый элемент в буфер: `temp = a[0]` (`temp = 4`).
2. В цикле для `i` от `0` до `n - 2` (то есть от `0` до `3`) сдвигаем элементы: `a[i] = a[i + 1]`.
3. На последнее место записываем значение из буфера: `a[n - 1] = temp`.

### Таблица трассировки сдвига

| Шаг | i | Действие | Буфер (temp) | Состояние массива a |
| :--- | :---: | :--- | :---: | :--- |
| До цикла | - | temp = a[0] | 4 | {4, 1, 7, 3, 9} |
| 1 | 0 | a[0] = a[1] | 4 | {1, 1, 7, 3, 9} |
| 2 | 1 | a[1] = a[2] | 4 | {1, 7, 7, 3, 9} |
| 3 | 2 | a[2] = a[3] | 4 | {1, 7, 3, 3, 9} |
| 4 | 3 | a[3] = a[4] | 4 | {1, 7, 3, 9, 9} |
| После цикла | - | a[4] = temp | 4 | {1, 7, 3, 9, 4} |

**Итоговый массив после сдвига:** `{1, 7, 3, 9, 4}`

## 2. Трассировка разворота массива на месте

Разворот выполняется для исходного массива `a = {4, 1, 7, 3, 9}` (`n = 5`, `n / 2 = 2`). На каждом шаге меняются местами элементы `a[i]` и `a[n - 1 - i]`.

### Таблица трассировки разворота

| Шаг | i | Индекс пары (n - 1 - i) | Обмениваемые элементы | Состояние массива после шага |
| :--- | :---: | :---: | :--- | :--- |
| Исходное | - | - | - | {4, 1, 7, 3, 9} |
| 1 | 0 | 4 | a[0] (4) и a[4] (9) | {9, 1, 7, 3, 4} |
| 2 | 1 | 3 | a[1] (1) и a[3] (3) | {9, 3, 7, 1, 4} |

*(Центральный элемент `a[2] = 7` остаётся на своём месте).*

**Ответы на вопросы:**
* **Сколько обменов выполнено:** Выполнено **2 обмена** (при `i = 0` и `i = 1`).
* **Почему цикл идёт только до `n / 2`:** За одну итерацию мы меняем местами сразу два симметричных элемента (с начала и с конца массива). Когда индекс `i` доходит до середины (`n / 2`), все пары уже переставлены. Если продолжить цикл до конца массива (`n`), то во второй половине элементы поменяются местами повторно, и массив вернётся в исходное (неразвёрнутое) состояние.

## 3. Ошибка в алгоритме поиска минимума при min = 0

* **Контрпример (массив, на котором алгоритм ошибается):** Любой массив, состоящий только из положительных чисел, например исходный массив **`a = {4, 1, 7, 3, 9}`** (или `{10, 20, 30}`).
* **Почему возникает ошибка:** Так как все элементы массива строго больше `0`, условие `if (a[i] < min)` ни разу не выполнится. В результате алгоритм вернёт `0` — число, которого вообще нет в массиве (вместо настоящего минимума `1`).
* **Как исправить начальное значение:** Нужно инициализировать переменную `min` **первым элементом массива**:
  `int min = a[0];`
  *(или использовать константу максимального значения типа `int min = int.MaxValue;`)*.
