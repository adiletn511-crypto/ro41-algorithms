## 1. Трассировка `s.Trim()` и `Split(';')`

**Исходная строка:** `s = "  Ахметов Ерлан;85 "`

1. **Шаг 1 (`s.Trim()`):** удаляет пробелы в начале и в конце строки.
   * Результат: `"Ахметов Ерлан;85"` (длина: 16).
2. **Шаг 2 (`Split(';')`):** разбивает строку по символу `;` на массив подстрок `string[]`.

| Индекс элемента | Содержимое элемента | Длина (`Length`) |
| :--- | :--- | :--- |
| `[0]` | `"Ахметов Ерлан"` | 13 |
| `[1]` | `"85"` | 2 |

## 2. Трассировка `Split(';')` и `int.TryParse`

**Исходная строка:** `line = "Иванов Пётр;70;85;x"`

После `line.Split(';')` образуется массив из 4 элементов. Оценка начинается с индекса `1` (так как `[0]` — это ФИО):

| Индекс | Часть (`parts[i]`) | Вызов `int.TryParse` | Результат (`bool`) | Значение `out` |
| :--- | :--- | :--- | :--- | :--- |
| `0` | `"Иванов Пётр"` | *(пропускается / ФИО)* | `false` | `0` |
| `1` | `"70"` | `int.TryParse("70", out val)` | `true` | `70` |
| `2` | `"85"` | `int.TryParse("85", out val)` | `true` | `85` |
| `3` | `"x"` | `int.TryParse("x", out val)` | `false` | `0` |

**Что вернёт `TryParseScores` и почему?**
Метод вернёт `false`. При обработке элемента с индексом `3` (`"x"`) метод `int.TryParse` не сможет преобразовать строку в число и вернёт `false`, из-за чего весь метод парсинга оценок завершится неудачей.

## 3. Сравнение `string` и `StringBuilder` в цикле

**Условие:** цикл `for (int i = 0; i < 4; i++)`

| Шаг (`i`) | Операция `s += i` (`string`) | Новых объектов `string` | Операция `sb.Append(i)` (`StringBuilder`) | Новых объектов `StringBuilder` |
| :--- | :--- | :--- | :--- | :--- |
| До цикла | `s = ""` | 1 (исходный `""`) | `sb = new StringBuilder()` | 1 (сам объект `sb`) |
| `i = 0` | `s = "0"` | +1 | буфер: `"0"` | 0 (меняется буфер) |
| `i = 1` | `s = "01"` | +1 | буфер: `"01"` | 0 |
| `i = 2` | `s = "012"` | +1 | буфер: `"012"` | 0 |
| `i = 3` | `s = "0123"` | +1 | буфер: `"0123"` | 0 |

* **Итого для `string`:** создаётся **5 объектов** `string` (1 начальная пустая строка + 4 новых объекта на каждой итерации цикла, так как строки неизменяемы).
* **Итого для `StringBuilder`:** создаётся **1 объект** `StringBuilder` (модифицируется внутренний буфер без создания новых объектов).

## 4. Почему после `s.ToUpper()` без присваивания `s` не изменилась?

Тип `string` в C# является **неизменяемым (immutable)**. Вызов `s.ToUpper()` не меняет исходную строку `s`, а **создаёт в памяти новую строку** в верхнем регистре. Если результат не присвоить обратно (`s = s.ToUpper();`), переменная `s` продолжит указывать на старую строку.
